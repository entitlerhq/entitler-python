# Security policy

Report a vulnerability privately through GitHub's private vulnerability reporting: open the
repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public
issue, pull request or discussion about it.

Include what you found, how to reproduce it and the versions affected. We will acknowledge the
report, keep you informed while we work on a fix, and credit you in the release notes unless you
would rather we did not.

Security fixes go into the newest release; see [versioning](docs/versioning.md).
